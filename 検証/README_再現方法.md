# 自動検証の再現方法（2026-11-25 改訂）

置き場所：`公開用/検証/`（リポジトリに含める。結果 `検証/結果/` は .gitignore で除外）。検証は架空の記録だけを使います。

## いちばん簡単な方法
```
python run_all.py
```
- この `検証` フォルダの1つ上（`公開用`）を一時フォルダへ写して（`検証` フォルダ自体は写さない）、**空いているポート**で配信し、t_core → t_more → t_face を実行します。
- 更新の試験用の v2ok／v2ng（版2・変換あり／なし）は一時フォルダの中に作ります。公開する画面のファイルには何も足しません。
- 結果は `結果/自動実行_日時/`（各テストの結果・まとめ・画面）に保存します。
- 必要なもの：`pip install playwright`。Chrome は自動で探します（`KARADA_CHROME` で指定も可）。

## 日付を固定しない
- 「過去の日」「天気の前日」などは、実行した日（日本時間）から数えます（`helpers.days_ago`）。
- 日付をまたぐ試験（日・月・年）は、ブラウザの時計をその日時にして行うので、いつ実行しても同じ結果になります。
- 別の日に実行した場合の確認：
  ```
  KARADA_FAKE_NOW=2027-03-01T21:30:00+09:00 python run_all.py
  ```
  2026-11-25 に、2027-01-01（年明け）と 2027-03-01（2月末をまたぐ）でも 21/21・29/29・37/37 を確認済み。

## 個別に実行する場合
- 配信先は `KARADA_URL`（既定 http://127.0.0.1:8765/ ※このPCでは別のアプリが使用中のことがあるため、run_all.py の利用を推奨）
- 一時ファイルの置き場所は `KARADA_TMP`（未指定なら一時フォルダを作成）
- `shots_real.py [保存先]`：画面の撮影（既定 `画面出力/`）
- `t_live.py <URL> <一時フォルダ> first|update <画面の保存先> <期待するキャッシュ名>`：公開URLでの確認

## 内容
| ファイル | 確かめること |
|---|---|
| t_core.py | 保存・書きかけ・取り消し・強制終了・過去の日・バックアップ・復元・PCの閲覧専用 |
| t_more.py | 日付の切り替わり・版の更新・天気・デモとの分離・バックアップ案内・通信なし |
| t_face.py | 「顔のこわばり・緊張」：任意入力・既存データ・修正・取り消し・バックアップ／復元・振り返り・320px幅 |

- 天気は Open-Meteo の公開仕様の形の応答（helpers.py の fake_wx）で試験しています。
